# 截圖朗讀小幫手（Mac 版）v1.6.1

Windows 版的 Mac 移植：**永遠浮在螢幕最上層**的小視窗。框選螢幕上任何地方（任何程式、網頁、PDF、影片字幕都可以），辨識裡面的文字並念給你聽，**念到哪、字就亮到哪**。

- 離線辨識：不用網路，支援**繁體中文**、簡體中文、英文
- 適用 Apple 晶片（M 系列）的 Mac
- 平常在螢幕**最上方選單列右側**有一個「讀」字小圖示（不佔 Dock）

## 第一次使用：兩個權限

1. 第一次開啟，如果出現「無法打開，因為無法確認開發者」：在 `截圖朗讀小幫手.app` 上按**右鍵 → 打開 → 打開**（只要做一次）。
2. **螢幕錄製**（一定要）：系統設定 → 隱私權與安全性 → 螢幕與系統錄音 → 打開「截圖朗讀小幫手」，然後**完全關閉程式再重開**。沒打開的話，截到的圖只有桌面背景。
3. 快捷鍵**不需要**額外權限。

## 基本操作

| 動作 | 按鈕 | 快捷鍵（預設，可自訂） |
|---|---|---|
| 框選螢幕範圍並朗讀 | 📷 框選截圖 | **Ctrl + Option + R** |
| 同一個範圍再截一次並朗讀（翻頁後） | ↻ 同一區 | **Ctrl + Option + E** |
| 停止朗讀 | ⏹ 停止 | **Ctrl + Option + S** |
| 語速加快／放慢（每按一次 ±1） | | **Ctrl + Option + → ／ ←** |
| 文字放大／縮小 | | **Ctrl + Option + ↑ ／ ↓** |
| 重新朗讀 | 🔊 朗讀 | |
| 暫停／播放（沒在念時按＝開始念） | ⏸ 暫停 | **Ctrl + Option + P** |
| 縮成浮動小圖案 | 右上角 ⊖ | |

（Windows 版的 Alt 在 Mac 上是 **Option**，Win 鍵是 **Cmd**。）

- 框選時：按住滑鼠拖曳；按 **Esc** 或按右鍵（兩指點一下）取消。
- **按住 ⌘（Command）或 Ctrl，在文字框裡點一下某個字，就從那個字開始往後念**（不想要可以取消「⌘ 或 Ctrl＋點字就從那裡開始念」）。
- **文字框裡的字可以直接編輯**：一般點一下就是放游標，可以打字、刪字、反白後刪除一大段。改好按「🔊 朗讀」就照改過的念。
- **反白一段再按「朗讀」**就只念那一段。
- 下一次截圖會換成新辨識的文字；改過的內容要保留，請先按「複製文字」。
- 文字框下方可以調整語音、語速、音量、透明度、**文字大小**、小圖案大小；按 ⚙ 可以把這一區收起來／打開。設定會自動記住。
- **朗讀中拉語速、音量，馬上就聽得到效果**。Google 語音變快變慢時，聲音還是同一個人。

## 文字方向（橫式／直式）

- **橫式**（預設）：一行一行由上到下，每行由左到右
- **直式**：一欄一欄**由右到左**，每欄**由上到下**（課本、直書、古詩用這個）

在文字框下方的「文字方向」切換，或浮動圖案右鍵 →「📐 文字方向」，或選單列圖示右鍵。剛截完圖再切換，文字框會馬上重新排列；如果文字框已經被你改過，就不會動它。

## 透明度與小紅點

透明度可以調到 **1%**。調到 **40% 以下**時，會出現一個一顯一透的**小紅點**，讓你找得到視窗：完整面板的小紅點在視窗最上方中間；小圖案的小紅點在圖案正中間（一樣可以點、右鍵、拖曳）。**滑鼠移到小紅點上**，視窗會暫時變清楚。

## 跟讀標示

朗讀時，正在念的字會**變成黃底、粗體、稍微放大**。不想要可以在 ⚙ 裡取消「跟讀標示」。

## 語音

- **電腦內建語音**（美佳、善怡、Eddy、Flo…）：不用網路。預設用「美佳（中文（台灣））」。要更好聽的語音：系統設定 → 輔助使用 → 朗讀內容 → 系統語音 → 管理語音，下載「中文（台灣）」的進階語音（Mac 版的語音由 macOS 提供，和 Windows 版的 Yating、Hanhan 不同）。
- **Google 國語（台灣）**：要有網路。會把要念的文字送到 Google 產生語音。沒有網路時會自動改用電腦內建語音。

## 浮動小圖案

按右上角 **⊖**，整個面板縮成一個藍色圓形「讀」字圖案：

- **拖曳**：移到螢幕任何位置
- **左鍵點一下**：打開完整面板
- **右鍵（兩指點一下）**：功能選單（框選截圖、同一區再截、重新朗讀、暫停、停止、語音、語速、音量、透明度、圖案大小、文字方向、截圖後自動朗讀、複製文字、多音字唸法設定、快捷鍵設定、打開完整面板、收到選單列、完全關閉程式）
- 縮小時按快捷鍵截圖，截完會**直接念**。顏色：藍＝待命、灰＝辨識中、橘（會閃）＝朗讀中、綠＝暫停。

## 關閉與選單列圖示

- 按完整面板左上角紅色 **×**，程式**不會關掉**，而是收到螢幕最上方選單列右側的「讀」字小圖示，快捷鍵照樣可以用。
- 選單列小圖示：**左鍵**打開完整面板；**右鍵（或 Ctrl＋點）**有選單（打開完整面板、顯示浮動圖案、框選截圖、暫停／播放、停止、語速、文字大小、橫式／直式閱讀、**完全關閉程式**）。
- 要真的關掉程式：選單列圖示或浮動圖案按右鍵 →「✖ 完全關閉程式」，或面板上的「✖ 完全關閉程式」按鈕。

## 每次打開程式的預設

完全關閉後再打開，一律是：**浮動圖案、透明度 100%、音量 100%、語速 0、Google 國語（台灣）語音**。（快捷鍵、文字大小、文字方向、多音字唸法、圖案位置等其他設定會記住。）

## 快捷鍵設定

⚙ →「快捷鍵設定…」。勾選 Ctrl / Option / Shift / Cmd，再選字母或數字。標「✖ 已被占用」的組合是系統或其他程式已經在用的，不能選。

## 多音字／破音字唸法

1. ⚙ →「多音字唸法設定…」，或在文字框**反白語詞 → 右鍵 →「設定『○○』的唸法」**
2. 「語詞」填 `銀行`，「唸成」用同音字填 `銀杭`，按「加入／更新」
3. 可以按「聽『語詞』原本怎麼念」和「聽『唸成』」比較

## 資料存放位置

`~/Library/Application Support/ScreenOCRReader/`：`settings.json`（設定）、`pronunciations.json`（多音字唸法）、`error.log`（錯誤記錄）。

## 和 Windows 版不一樣的地方

- 圖示在選單列（螢幕上方），不是右下角工作列。
- 內建語音是 macOS 的語音；Google 語音一樣。
- 需要「螢幕錄製」權限。
- 沒有 Apple 簽章，第一次要按右鍵 → 打開。

## 給開發者

- 程式：`src/screen_ocr_reader.py`（Windows 與 Mac 共用一份，用 `IS_MAC` 分流）
- Mac 專用：`MacSpeaker`（NSSpeechSynthesizer）、`MacGlobalHotkeys`（Carbon RegisterEventHotKey）、`MacTrayIcon`（NSStatusItem）、`make_borderless`／`mac_float`（視窗層級）
- 本機執行：`.venv/bin/python src/screen_ocr_reader.py`（需要有 tkinter 的 Python 3.12：`brew install python@3.12 python-tk@3.12`）
- 打包：`./build_mac.sh` → `dist/截圖朗讀小幫手.app`
- 自我檢查：`截圖朗讀小幫手.app/Contents/MacOS/截圖朗讀小幫手 --selftest result.txt`
