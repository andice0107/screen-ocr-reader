# 截圖朗讀小幫手（Screen OCR Reader）v1.6.1

一個**永遠浮在螢幕最上層**的小視窗。框選螢幕上任何地方（任何程式、網頁、PDF、影片字幕都可以），它會辨識裡面的文字並念給你聽，**念到哪、字就亮到哪**。

- 免安裝：雙擊 `ScreenOCRReader.exe` 就能用
- 離線辨識：不用網路，支援**繁體中文**、簡體中文、英文
- 適用 Windows 10 / 11（64 位元）

第一次開啟若出現「Windows 已保護您的電腦」，請按「其他資訊」→「仍要執行」。第一次啟動需要幾秒鐘解壓縮，請稍等。

## 基本操作

| 動作 | 按鈕 | 快捷鍵（預設，可自訂） |
|---|---|---|
| 框選螢幕範圍並朗讀 | 📷 框選截圖 | **Ctrl + Alt + R** |
| 同一個範圍再截一次並朗讀（翻頁後） | ↻ 同一區 | **Ctrl + Alt + E** |
| 停止朗讀 | ⏹ 停止 | **Ctrl + Alt + S** |
| 語速加快／放慢（每按一次 ±1） | | **Ctrl + Alt + → ／ ←** |
| 文字放大／縮小 | | **Ctrl + Alt + ↑ ／ ↓** |
| 重新朗讀 | 🔊 朗讀 | |
| 暫停／播放（沒在念時按＝開始念） | ⏸ 暫停 | **Ctrl + Alt + P** |
| 縮成浮動小圖案 | 右上角 ⊖ | |

- 框選時：按住滑鼠左鍵拖曳；按 **Esc** 或滑鼠右鍵取消。
- **按住 Ctrl，在文字框裡點一下某個字，就從那個字開始往後念**（不想要可以取消「Ctrl＋點字就從那裡開始念」）。
- **文字框裡的字可以直接編輯**：一般點一下就是放游標，可以打字、刪字（Delete／Backspace）、反白後刪除一大段。改好按「🔊 朗讀」就照改過的念。
- **反白一段再按「朗讀」**就只念那一段。
- 下一次截圖會換成新辨識的文字；改過的內容要保留，請先按「複製文字」。
- 文字框下方可以調整語音、語速、音量、透明度、**文字大小**、小圖案大小；按 ⚙ 可以把這一區收起來／打開。設定會自動記住。
- **朗讀中拉語速、音量，馬上就聽得到效果**。Google 語音變快變慢時，聲音還是同一個人（不會變成卡通聲）。
- 面板最下方一直顯示目前的快捷鍵。

## 文字方向（橫式／直式）

截圖裡的文字可以選擇怎麼念：

- **橫式**（預設）：一行一行由上到下，每行由左到右
- **直式**：一欄一欄**由右到左**，每欄**由上到下**（課本、直書的文章、古詩用這個）

在文字框下方的「文字方向」切換，或浮動圖案右鍵 →「📐 文字方向」，或右下角圖示右鍵。
剛截完圖再切換方向，文字框會**馬上重新排列**（不用再截一次）；如果文字框已經被你改過，就不會動它，下次截圖才用新方向。這個設定會記住。

## 透明度與小紅點

透明度可以調到 **1%**。調到 **40% 以下**時，視窗上會出現一個**會像呼吸燈一樣「一顯一透」慢慢浮現又消失的小紅點**，讓你找得到它：

- 完整面板：小紅點在視窗最上方中間
- 小圖案：小紅點在圖案正中間（一樣可以點它、右鍵、拖曳）
- **滑鼠移到小紅點上**，視窗會暫時變清楚；滑鼠離開後恢復透明

## 跟讀標示

朗讀時，正在念的字會**變成黃底、粗體、稍微放大**，跟著聲音往下走。不想要可以在 ⚙ 裡取消「跟讀標示」。

## 語音

- **電腦內建語音**（Yating、Hanhan、Zhiwei）：不用網路。如果選單裡沒有中文語音，請到「設定 → 時間與語言 → 語音 → 新增語音」加入「中文（台灣）」。
- **Google 國語（台灣）**：要有網路。會把要念的文字送到 Google 產生語音。沒有網路時會自動改用電腦內建語音。

## 浮動小圖案

按右上角 **⊖**，整個面板會縮成一個藍色圓形「讀」字圖案：

- **拖曳**：移到螢幕任何位置
- **左鍵點一下**：打開完整面板
- **右鍵**：功能選單（框選截圖、同一區再截、重新朗讀、暫停、停止、語音、語速、音量、透明度、圖案大小、文字方向、截圖後自動朗讀、複製文字、多音字唸法設定、快捷鍵設定、打開完整面板、收到右下角圖示、完全關閉程式）
- 縮小時按快捷鍵截圖，截完會**直接念**。圖案顏色：藍＝待命、灰＝辨識中、橘（會閃）＝朗讀中、綠＝暫停。

## 關閉與右下角圖示

- 按完整面板右上角的 **×**，程式**不會關掉**，而是收到工作列右下角（時鐘旁邊，可能要按 **^** 展開）的「讀」字小圖示，快捷鍵照樣可以用。
- 右下角小圖示：**左鍵**打開完整面板；**右鍵**有選單（打開完整面板、顯示浮動圖案、框選截圖、暫停／播放、停止、語速、文字大小、橫式／直式閱讀、**完全關閉程式**）。
- 要真的關掉程式：右下角圖示或浮動圖案按右鍵 →「✖ 完全關閉程式」，或面板上的「✖ 完全關閉程式」按鈕。

## 每次打開程式的預設

完全關閉後再打開，一律是：**浮動圖案、透明度 100%、音量 100%、語速 0、Google 國語（台灣）語音**。
（快捷鍵、文字大小、文字方向、多音字唸法、圖案位置等其他設定會記住。）

## 快捷鍵設定

⚙ →「快捷鍵設定…」（或小圖案右鍵選單）。勾選 Ctrl / Alt / Shift / Win，再選字母或數字。
清單中標「✖ 已被占用」的組合，是 Windows 或其他程式已經在用的，不能選。

## 多音字／破音字唸法

電腦有時會唸錯多音字，例如「銀行」的「行」。

1. ⚙ →「多音字唸法設定…」，或在文字框**反白語詞 → 右鍵 →「設定『○○』的唸法」**
2. 「語詞」填 `銀行`，「唸成」用同音字填 `銀杭`，按「加入／更新」
3. 可以按「聽『語詞』原本怎麼念」和「聽『唸成』」比較

只會改到這個語詞，其他地方的「行」不受影響。語詞寫長一點會更準。

## 資料存放位置

`%APPDATA%\ScreenOCRReader\`：`settings.json`（設定）、`pronunciations.json`（多音字唸法）、`error.log`（錯誤記錄）。

## 給開發者

- 程式：`src/screen_ocr_reader.py`（Python 3.12 + tkinter；OCR：RapidOCR 3.10 / PP-OCRv6；截圖：mss；朗讀：Windows SAPI 與 gTTS（miniaudio 播放、WSOLA 不變調變速））
- 本機執行：`run_dev.bat`；本機打包：`build_local.bat`
- 自我檢查：`ScreenOCRReader.exe --selftest result.txt`
